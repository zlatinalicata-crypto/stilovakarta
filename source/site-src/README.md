# Стилова карта

Сайтът stilovakarta.com (stilovakarta.bg води към него). Тестовете и прегледът са безплатни, пълният резултат се отключва с плащане през Stripe: въвеждаща цена 4,99 € до 28.02.2027, после 19,99 €. Датата се сменя на две места: `promoUntil` в `source/src/app.js` и `PROMO_UNTIL` в `lib/pay.js`.

## Как е устроен

- `public/`: страниците, които вижда посетителят. Там няма палитри и формули.
- `lib/`: изчисленията и пълният резултат. Работят само на сървъра.
- `netlify/functions/`: `/api/report` дава прегледа, а пълния резултат само за платена поръчка, и то за данните, с които е платена. `/api/checkout` отваря плащането в Stripe.

## Пускане в Netlify

1. В Netlify: **Add new site → Import an existing project → GitHub → stilovakarta**. Настройките идват от `netlify.toml`, не пипай нищо.
2. **Site configuration → Environment variables** добави:
   - `STRIPE_SECRET_KEY`: тестовият ключ от Stripe (започва със `sk_test_`), от Developers → API keys.
   - `TEST_MODE` = `1`: показва бутона „Тестов режим“. **Махни го преди истинското пускане.**
3. **Deploys → Trigger deploy**.

## Тест на плащането

Плати с тестова карта `4242 4242 4242 4242`, произволна бъдеща дата и произволен CVC. След плащането пълният резултат трябва да се отвори сам. Тестово плащане отключва резултата **само докато `TEST_MODE` = `1`**. Без `TEST_MODE` сайтът приема само истински плащания. Докато ключът е тестов и няма `TEST_MODE`, вместо бутона за плащане стои „Плащането с карта ще бъде включено съвсем скоро“, а кодовете работят. С live ключа бутонът се връща сам.

## Домейн

Домейните са в SuperHosting.bg, пощата също остава там.

1. В Netlify: **Domain management → Add a domain → stilovakarta.com** (Netlify добавя и `www` сам), после **Add domain alias** за `stilovakarta.bg` и `www.stilovakarta.bg`.
2. В SuperHosting → DNS зона на всеки домейн: запис **A** за самия домейн → `75.2.60.5`, запис **CNAME** за `www` → `stilovakarta.netlify.app`. Ако има **AAAA** запис за домейна или `www`, изтрий го. MX записите и `mail` не се пипат. Ако MX сочи към самия домейн, първо направи A запис `mail` към старото IP и насочи MX към `mail.<домейн>`.
3. Netlify издава SSL сертификата сам след няколко минути до няколко часа (Domain management → HTTPS).

## Истинско пускане

1. Попълни маркираните полета в `public/terms.html` и `public/privacy.html`.
2. Смени `STRIPE_SECRET_KEY` с live ключа (`sk_live_`) и изтрий `TEST_MODE`.
3. Направи нов deploy и плати веднъж с истинска карта, за да провериш.

## Кодове

Полето „Имам код за отстъпка“ е на сайта, преди плащането. Кодовете се проверяват на сървъра и не се виждат в кода на страницата: в `lib/pay.js` (`CODES`) стои само SHA-256 отпечатък на кода с малки букви.

- `glossbowen`: −15 % от текущата цена.
- `otmen`: отключва пълния резултат безплатно, без Stripe.

Нов код: `node -e "console.log(require('crypto').createHash('sha256').update('kod').digest('hex'))"` и добави реда в `CODES` (`{ pct: 20 }` за отстъпка или `{ free: true }`). За да спреш код, изтрий реда му.
